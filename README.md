Rule-Based AI Chatbot

Description:

This project is a simple rule-based chatbot developed in Python as part of the DecodeLabs Internship.
The chatbot interacts with users by recognizing predefined text inputs and responding with appropriate messages. It demonstrates the use of Python fundamentals including loops, conditional statements, user input, and string manipulation.

## Features

- Greets the user
- Responds to simple questions
- Converts input to lowercase for easier matching
- Handles unknown inputs gracefully
- Allows the user to exit the chatbot using the `exit` command

## How to Run

### 1. Clone the repository

```bash
git clone https://github.com/ahmedyar-8085/DecodeLabs-Internship.git
```

### 2. Move into the project folder

```bash
cd DecodeLabs-Internship
```

### 3. Run the chatbot

```bash
python chatbot.py
```

If your system uses Python 3 specifically, run:

```bash
python3 chatbot.py
```
